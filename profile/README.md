**OnlyWorlds** is an open standard for worldbuilding data: one shape for a world's characters, locations, institutions, events and the rest of its 22 element types, which any tool can read and write.

**The standard**
- [OnlyWorlds](https://github.com/OnlyWorlds/OnlyWorlds): the schema, 22 element types in YAML
- [schema-dist](https://github.com/OnlyWorlds/schema-dist): the schema packaged for tools, with a reference decoder

**Build on it**
- [sdk](https://github.com/OnlyWorlds/sdk): TypeScript (`npm install @onlyworlds/sdk`)
- [python-sdk](https://github.com/OnlyWorlds/python-sdk): Python (`pip install onlyworlds`)
- [unity-sdk](https://github.com/OnlyWorlds/unity-sdk): Unity and C#
- [toolkit](https://github.com/OnlyWorlds/toolkit): Claude Code skills for building and using worlds
- [event-starter](https://github.com/OnlyWorlds/event-starter): a starting point for a web tool on world data, ready to deploy
- [tools](https://github.com/OnlyWorlds/tools): the list of tools built on OnlyWorlds, and how a tool gets on it

**With AI**
- An agent reads a world through the [API](https://www.onlyworlds.com/api/docs) or [MCP](https://www.onlyworlds.com/mcp), and joins one from a single invitation link ([how](https://www.onlyworlds.com/join)).

**Use a world**
- [atlas](https://github.com/OnlyWorlds/atlas): a desktop worldbuilding studio, your world in a folder on your own computer
- [lantern](https://github.com/OnlyWorlds/lantern): an offline-first phone app that holds your worlds
- [little-lens](https://github.com/OnlyWorlds/little-lens): a world as a web of its elements, read only
- [parlor](https://github.com/OnlyWorlds/parlor): a room on a world, where people and their AI meet and leave with elements built into it
- [obsidian-plugin](https://github.com/OnlyWorlds/obsidian-plugin): a world as Obsidian notes, synced both ways
- [azgaar-converter](https://github.com/OnlyWorlds/azgaar-converter): an Azgaar map export into a world
- [foundry-converter](https://github.com/OnlyWorlds/foundry-converter): a world into an installable Foundry VTT module

Make a world in [Atlas](https://atlas.onlyworlds.com) or host one on [onlyworlds.com](https://www.onlyworlds.com). Docs: [onlyworlds.github.io](https://onlyworlds.github.io). The schema changes through the [Council](https://council.onlyworlds.com). Something wrong or missing: the [feedback](https://github.com/OnlyWorlds/feedback) tracker. How we treat each other here, people and agents alike: the [code of conduct](https://github.com/OnlyWorlds/OnlyWorlds/blob/main/CODE_OF_CONDUCT.md).
