**OnlyWorlds** is an open standard for worldbuilding data: one shape for a world's characters, locations, institutions, events and the rest of its 22 element types, which any tool can read and write.

**The standard**
- [OnlyWorlds](https://github.com/OnlyWorlds/OnlyWorlds): the schema, 22 element types in YAML
- [schema-dist](https://github.com/OnlyWorlds/schema-dist): the schema packaged for tools, with a reference decoder

**Build on it**
- [sdk](https://github.com/OnlyWorlds/sdk): TypeScript (`npm install @onlyworlds/sdk`)
- [python-sdk](https://github.com/OnlyWorlds/python-sdk): Python (pre-release)
- [unity-sdk](https://github.com/OnlyWorlds/unity-sdk): Unity and C#
- [toolkit](https://github.com/OnlyWorlds/toolkit): Claude Code skills for building and using worlds

**With AI**
- An agent reads a world through the [API](https://www.onlyworlds.com/api/docs) or [MCP](https://www.onlyworlds.com/mcp), and joins one from a single invitation link ([how](https://www.onlyworlds.com/join)).

**Use a world**
- [obsidian-plugin](https://github.com/OnlyWorlds/obsidian-plugin): a world as Obsidian notes, synced both ways
- [azgaar-converter](https://github.com/OnlyWorlds/azgaar-converter): an Azgaar map export into a world

Make a world in [Atlas](https://atlas.onlyworlds.com) or host one on [onlyworlds.com](https://www.onlyworlds.com). Docs: [onlyworlds.github.io](https://onlyworlds.github.io). The schema changes through the [Council](https://council.onlyworlds.com).
